## 🇬🇧 v7 – game options, metadata editor and media viewer on the top screen

Dual-screen EmulationStation mod for the **Anbernic RG DS Plus** on **ROCKNIX**.

### What's new
- **Game options** open as a centered menu on the top screen (like the other menus, incl. BACK button) instead of a narrow full-height side panel
- **Edit this game's metadata** stays on the top screen
- **View game media** shows images and videos on the top screen only instead of stretching them across both screens
- **Ports switch remembers your theme per mode**: the last theme used in single and dual mode is restored when switching
- **canvas-ds support**: layout overlay for [canvas-ds](https://github.com/toniremi/canvas-ds) by toniremi in `theme/canvas-ds-rgds-plus-overlay/` (shared with permission, CC BY-NC-SA)

### Downloads
- `dii-ess-aye-rocknix-dual-mod-v7.tar.gz` – complete package: ES binary, device scripts, essway drop-in, RG DS Plus theme, docs and licenses
- `emulationstation-rgds-v7` – ES binary only (aarch64)

### Upgrading from v6
```
systemctl stop essway
```
Copy `emulationstation-rgds-v7` to `/storage/rgds-test/`, then:
```
chmod +x /storage/rgds-test/emulationstation-rgds-v7
sed -i 's/emulationstation-rgds-v6/emulationstation-rgds-v7/' /storage/rgds-test/start-es-v2-diag.sh
systemctl start essway
```

### Requirements · Limitations
- Anbernic RG DS Plus with ROCKNIX (tested with 20261001, ES commit cada856)
- No ScreenScraper / RetroAchievements in this build – switch to stock ES via Ports to scrape

## 🇩🇪 v7 – Spieloptionen, Metadaten-Editor und Medienansicht auf dem oberen Bildschirm

Dual-Screen-EmulationStation für das **Anbernic RG DS Plus** mit **ROCKNIX**.

### Neu
- **Spieloptionen** öffnen als zentriertes Menü auf dem oberen Bildschirm (wie die anderen Menüs, mit ZURÜCK) statt als schmale Seitenleiste
- **Metadaten bearbeiten** bleibt auf dem oberen Bildschirm
- **Spielmedien ansehen** zeigt Bilder und Videos nur oben, statt sie über beide Bildschirme zu strecken
- **Umschalten über Ports merkt sich das Theme je Modus**: das zuletzt genutzte Theme im Single- und Dual-Modus wird wiederhergestellt
- **canvas-ds-Unterstützung**: Layout-Overlay für [canvas-ds](https://github.com/toniremi/canvas-ds) von toniremi in `theme/canvas-ds-rgds-plus-overlay/` (mit Erlaubnis, CC BY-NC-SA)

### Downloads
- `dii-ess-aye-rocknix-dual-mod-v7.tar.gz` – komplettes Paket: ES-Binary, Geräteskripte, essway-Drop-in, RG-DS-Plus-Theme, Doku und Lizenzen
- `emulationstation-rgds-v7` – nur das ES-Binary (aarch64)

### Aktualisieren von v6
Befehle wie oben: ES stoppen, `emulationstation-rgds-v7` nach `/storage/rgds-test/` kopieren, ausführbar machen, Startskript anpassen, ES starten.

### Voraussetzungen · Einschränkungen
- Anbernic RG DS Plus mit ROCKNIX (getestet mit 20261001, ES-Commit cada856)
- Kein ScreenScraper / keine RetroAchievements in diesem Build – zum Scrapen per Ports auf das Original-ES wechseln
