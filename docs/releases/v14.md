# RetroDualStation v14

## 🇬🇧 What's new

- **Support for the Anbernic RG DS** (640 × 480 per screen) in addition to the RG DS Plus – same
  ZIP, the installer detects the device. ES, Control Center, Game switcher, Power menu, Artwork Manager
  and the tour adapt to the screen size; touch uses the bottom screen.
- **New name everywhere: RDS.** Ports entries are now *Install RDS*, *RDS Dual-Screen*, *RDS Single-Screen*,
  *Uninstall RDS* and *Artwork Manager* – with icons, a short description, version, release date and developer.
  The description follows the ES language at install time. The download is now `retrodualstation-v14.zip`.
- **Themes with device-neutral names that honour their creators:** **canvas rds** (based on toniremi's canvas-ds)
  and **dii-ess-aye rds** (based on beebono's dii-ess-aye). Your theme choice and canvas settings move over.
- ES menus on the RG DS use a centred window like on the RG DS Plus. The menu text is a bit larger than
  true to scale on purpose (easier to read on the smaller screens) – some menus scroll.

### Fixes – also for fresh ROCKNIX installs on the RG DS Plus
- RetroArch: network commands are switched on – without them saving, loading and quitting via the
  Control Center and Game switcher did not work on a fresh ROCKNIX.
- RetroArch: ROCKNIX's automatic hotkeys are switched off – they overrode the unified shortcuts.
- ES savestate manager is switched off (the Control Center handles save slots).
- The ROCKNIX volume/brightness popup is hidden even if its config is created after installing.
- DraStic: menu on R3, fast forward on the right stick on both devices – the Anbernic button stays with the Control Center.
- Screenshot tile in RetroArch: creates the screenshots folder.
- Control Center: RetroArch is quit reliably even if it does not respond to the quit command.
- Button page: RetroArch's menu combo is no longer listed (one concept: Anbernic + X).
- ES: no huge HTML page as RetroAchievements error message.

### Install / update
Unpack `retrodualstation-v14.zip` into `/storage/roms/ports` and run *Ports → Install RDS*.
Updating from v13.1 removes the old Ports entries and themes automatically.
Set up RetroAchievements in ES (*Main menu → RetroAchievements*), not in RetroArch.

## 🇩🇪 Neu

- **Unterstützung für das Anbernic RG DS** (640 × 480 je Bildschirm) zusätzlich zum RG DS Plus – dieselbe
  ZIP, der Installer erkennt das Gerät. ES, Kontrollcenter, Gameswitcher, Power-Menü, Artwork Manager und
  die Tour passen sich der Bildschirmgröße an; Touch nutzt den unteren Bildschirm.
- **Neuer Name überall: RDS.** Die Ports-Einträge heißen jetzt *Install RDS*, *RDS Dual-Screen*, *RDS Single-Screen*,
  *Uninstall RDS* und *Artwork Manager* – mit Icon, kurzer Beschreibung, Version, Release-Datum und Entwickler.
  Die Beschreibung folgt der ES-Sprache bei der Installation. Der Download heißt jetzt `retrodualstation-v14.zip`.
- **Themes mit geräteneutralen Namen zu Ehren ihrer Ersteller:** **canvas rds** (auf Basis von toniremis canvas-ds)
  und **dii-ess-aye rds** (auf Basis von beebonos dii-ess-aye). Deine Theme-Auswahl und canvas-Einstellungen ziehen mit um.
- ES-Menüs auf dem RG DS nutzen ein zentriertes Fenster wie auf dem RG DS Plus. Die Menüschrift ist bewusst
  etwas größer als maßstabsgetreu (besser lesbar auf den kleineren Bildschirmen) – manche Menüs scrollen.

### Behoben – auch bei frisch installiertem ROCKNIX auf dem RG DS Plus
- RetroArch: Netzwerkbefehle werden eingeschaltet – ohne sie gingen Speichern, Laden und Beenden über
  Kontrollcenter und Gameswitcher bei frischem ROCKNIX nicht.
- RetroArch: die automatischen Hotkeys von ROCKNIX werden ausgeschaltet – sie überdeckten die einheitlichen Kürzel.
- Der ES-Savestate-Manager ist aus (Speicherplätze verwaltet das Kontrollcenter).
- Die ROCKNIX-Anzeige für Lautstärke/Helligkeit wird ausgeblendet, auch wenn ihre Konfiguration erst nach der Installation entsteht.
- DraStic: Menü auf R3, Vorspulen auf dem rechten Stick auf beiden Geräten – die Anbernic-Taste bleibt beim Kontrollcenter.
- Screenshot-Kachel in RetroArch: legt den Screenshot-Ordner an.
- Kontrollcenter: beendet RetroArch zuverlässig, auch wenn es auf den Beenden-Befehl nicht reagiert.
- Tastenseite: Die Menü-Kombination von RetroArch wird nicht mehr angezeigt (ein Konzept: Anbernic + X).
- ES: keine riesige HTML-Seite mehr als RetroAchievements-Fehlermeldung.

### Installieren / Aktualisieren
`retrodualstation-v14.zip` nach `/storage/roms/ports` entpacken und *Ports → Install RDS* starten.
Beim Update von v13.1 werden alte Ports-Einträge und Themes automatisch entfernt.
RetroAchievements in ES einrichten (*Hauptmenü → RetroAchievements*), nicht in RetroArch.
