# RetroDualStation v15.1

## 🇬🇧 What's new

### Colours that follow your theme
- **Automatic mode**: the light/dark switch in the Control Center now cycles **dark → light → automatic**.
  In automatic mode the Control Center, game switcher, power menu and notifications take the colours of the
  ES theme – background like the ES menu, accent like the selection. With canvas rds: **Famicom** red with gold,
  **SNES** purple, **Neon** pink, **Sony** blue, **Retro** teal, **Pastel** light blue, **Dark/Light** neutral grey.
  Changing the scheme in ES applies the next time you open the Control Center.
- **16 accent colours like on the DS**: in dark and light mode the colour dot opens a palette with the 16 colours
  of the Nintendo DS / DSi user profile – with live preview, **A** applies, **B** goes back.
- Text on light accents (yellow, lime, pastel …) automatically turns dark, so everything stays readable.
- Notifications on top now follow light, dark and automatic mode, too.

### Control Center
- **Larger save-slot previews** – the slot menu uses the full height.
- Slightly larger text for hints and small labels; on the RG DS hints are one step larger again.

### Under the hood
- Diagnostics for rare hangs: `pkill -USR1 -f rds_cc.py` (Control Center) or `pkill -USR1 -f rds_artwork.py`
  (Artwork Manager) writes the current position of every thread to the log.

### Install / update
Unpack `retrodualstation-v15.1.zip` into `/storage/roms/ports` and run *Ports → Install RDS*.

## 🇩🇪 Neu

### Farben, die deinem Theme folgen
- **Automatik-Modus**: Der Hell/Dunkel-Schalter im Kontrollcenter wechselt jetzt **Dunkel → Hell → Automatisch**.
  Bei Automatisch übernehmen Kontrollcenter, Gameswitcher, Power-Menü und Meldungen die Farben des ES-Themes –
  Hintergrund wie das ES-Menü, Akzent wie die Auswahl. Mit canvas rds: **Famicom** rot mit Gold, **SNES** lila,
  **Neon** pink, **Sony** blau, **Retro** petrol, **Pastel** hellblau, **Dark/Light** neutral grau.
  Ein Schemawechsel in ES wirkt beim nächsten Öffnen des Kontrollcenters.
- **16 Akzentfarben wie beim DS**: Bei Dunkel und Hell öffnet der Farbpunkt eine Auswahl mit den 16 Farben des
  Benutzerprofils von Nintendo DS / DSi – mit Vorschau, **A** übernimmt, **B** zurück.
- Schrift auf hellen Akzenten (Gelb, Hellgrün, Pastell …) wird automatisch dunkel – alles bleibt lesbar.
- Die Meldungen oben folgen jetzt ebenfalls Hell, Dunkel und Automatisch.

### Kontrollcenter
- **Größere Vorschaubilder bei den Speicherplätzen** – das Slot-Menü nutzt die volle Höhe.
- Etwas größere Schrift bei Hinweisen und kleinen Beschriftungen; auf dem RG DS die Hinweise noch eine Stufe größer.

### Unter der Haube
- Diagnose bei seltenen Hängern: `pkill -USR1 -f rds_cc.py` (Kontrollcenter) bzw. `pkill -USR1 -f rds_artwork.py`
  (Artwork Manager) schreibt die aktuelle Stelle aller Threads ins Log.

### Installieren / Aktualisieren
`retrodualstation-v15.1.zip` nach `/storage/roms/ports` entpacken und *Ports → Install RDS* starten.
