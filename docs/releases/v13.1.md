# RetroDualStation v13.1

## 🇬🇧 What's new

- **Vibration feedback** – a short pulse when opening the Control Center, Game switcher and Power menu,
  when switching pages (L1/R1, swipe), when tapping in the Control Center and when choosing a game.
  A new achievement gives a double pulse. Switch it off with the new icon at the top of the Control Center.

### Fixes
- RetroAchievements page: the Softcore/Hardcore label is readable in the light theme.
- ES main menu *RetroAchievements*: opens the RetroAchievements settings with a hint to page 3 of the Control Center instead of an error.

### Install / update
Unpack `rocknix-dualstation-v13.1.zip` into `/storage/roms/ports` and run *Ports → Install ROCKNIX DualStation*.

## 🇩🇪 Neu

- **Vibration** – ein kurzer Impuls beim Öffnen von Kontrollcenter, Gameswitcher und Power-Menü,
  beim Seitenwechsel (L1/R1, Wischen), beim Antippen im Kontrollcenter und bei der Spielwahl.
  Ein neuer Erfolg gibt einen doppelten Impuls. Abschalten über das neue Symbol oben im Kontrollcenter.

### Behoben
- RetroAchievements-Seite: Die Anzeige Softcore/Hardcore ist im hellen Design lesbar.
- ES-Hauptmenü *RetroAchievements*: öffnet die RetroAchievements-Einstellungen mit Hinweis auf Seite 3 im Kontrollcenter statt eines Fehlers.

### Installieren / Aktualisieren
`rocknix-dualstation-v13.1.zip` nach `/storage/roms/ports` entpacken und *Ports → Install ROCKNIX DualStation* starten.
