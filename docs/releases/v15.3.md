# RetroDualStation v15.3

## 🇬🇧 What's new

### Restart and save in every emulator
- **Restart works in DraStic and DSperate** – from the Control Center (*Restart*) and with **Y** in the game switcher.
  The game really starts from the beginning (DSperate no longer loads its automatic save point).
- **RetroArch restart without the "Reset" message** – a short "Restarting …" screen covers it.
- **DraStic: save and load only with Anbernic + R2 / L2** – R2 or L2 alone no longer save or load by accident
  (DraStic has no button combinations; the Control Center translates them, like menu and fast forward).

### RetroArch display
- **FPS works again** with **Anbernic + Y** – in RetroArch's usual style (white on a dark tile).
- No more **"Paused"** tile when the Control Center or game switcher opens – RetroArch is frozen like the other
  emulators instead of paused. Touching the bottom screen no longer pauses RetroArch either.
- All other RetroArch notifications stay off (save, load, fast forward, screenshot, achievement summary at start …) –
  the Control Center shows its own messages.

### Faster and smoother
- Switching from a DraStic game to **another** RetroArch game: the parked game is no longer shown briefly and the
  switch is a bit quicker.

### Updating from older versions
- **Save states move to the new slots automatically** (once): users of v15.1 or older keep all their states – the old
  game-switcher state becomes the automatic save point, own states move to free slots 1–9. A fresh installation moves
  states from slot 0 to a free slot so the automatic save point never overwrites them.
- The hint for creating game lists now says to use the **scraper in ES** (works in dual mode since v15).

Updating: copy the package into **ports** and start **Update RDS**.

## 🇩🇪 Neu

### Neu starten und Speichern in jedem Emulator
- **Neu starten funktioniert in DraStic und DSperate** – im Kontrollcenter (*Neu starten*) und mit **Y** im
  Gameswitcher. Das Spiel beginnt wirklich von vorn (DSperate lädt seinen automatischen Speicherpunkt nicht mehr).
- **RetroArch-Neustart ohne „Reset“-Meldung** – ein kurzer Bildschirm „Wird neu gestartet …“ verdeckt sie.
- **DraStic: Speichern und Laden nur mit Anbernic + R2 / L2** – R2 oder L2 allein speichern bzw. laden nicht mehr
  versehentlich (DraStic kennt keine Tastenkombinationen; das Kontrollcenter übersetzt sie, wie bei Menü und Vorspulen).

### RetroArch-Anzeige
- **FPS geht wieder** mit **Anbernic + Y** – im gewohnten RetroArch-Stil (weiß auf dunkler Kachel).
- Keine **„Pausiert“**-Kachel mehr, wenn Kontrollcenter oder Gameswitcher öffnen – RetroArch wird wie die anderen
  Emulatoren eingefroren statt pausiert. Auch eine Berührung des unteren Bildschirms pausiert RetroArch nicht mehr.
- Alle anderen RetroArch-Einblendungen bleiben aus (Speichern, Laden, Vorspulen, Screenshot, Erfolge-Übersicht beim
  Start …) – die Meldungen zeigt das Kontrollcenter.

### Schneller und ruhiger
- Wechsel von einem DraStic-Spiel zu einem **anderen** RetroArch-Spiel: Das geparkte Spiel blitzt nicht mehr kurz auf,
  und der Wechsel ist etwas schneller.

### Update von älteren Versionen
- **Savestates ziehen einmalig auf die neuen Slots um**: Wer von v15.1 oder älter kommt, behält alle Stände – der
  alte Gameswitcher-Stand wird zum automatischen Speicherpunkt, eigene Stände wandern in freie Slots 1–9. Bei einer
  Neuinstallation wandern Stände von Platz 0 in einen freien Slot, damit der automatische Speicherpunkt sie nie
  überschreibt.
- Der Hinweis zum Anlegen der Spielelisten nennt jetzt den **Scraper in ES** (geht seit v15 auch im Dual-Modus).

Update: Paket in **ports** kopieren und **Update RDS** starten.
