## 🇬🇧 v9

- New game list views for canvas-ds: **Gamecarousel, Detailed, Grid, Showcase and Spotlight** (`canvas-ds-rgds-plus-v9.zip`).
- In dual mode, left/right in the game list no longer jumps to another system; L2/R2 still do. Single mode keeps your own setting.
