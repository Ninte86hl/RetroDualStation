# RetroDualStation v15.2.1

## 🇬🇧 What's new
- **Restarting RetroArch games works again** – from the Control Center (*Restart*), with **Y** in the game switcher
  and when the game switcher starts a game fresh. RetroArch 1.22 asks for confirmation before restarting; RDS hides
  that message, so a single restart command had no effect. RDS now confirms it automatically.
- **Installer:** RetroArch settings that RDS needs are now added if they are missing (fresh ROCKNIX or after
  uninstalling), instead of only being changed when present.

Updating from v15.2: copy the package into **ports** and start **Update RDS**.

## 🇩🇪 Neu
- **Neustart von RetroArch-Spielen funktioniert wieder** – im Kontrollcenter (*Neu starten*), mit **Y** im
  Gameswitcher und wenn der Gameswitcher ein Spiel frisch startet. RetroArch 1.22 fragt vor dem Neustart nach; RDS
  blendet diese Meldung aus, deshalb blieb ein einzelner Neustart-Befehl ohne Wirkung. RDS bestätigt jetzt selbst.
- **Installer:** Einstellungen, die RDS in RetroArch braucht, werden jetzt hinzugefügt, wenn sie fehlen (frisches
  ROCKNIX oder nach einer Deinstallation) – statt nur geändert, wenn sie schon da sind.

Update von v15.2: Paket in **ports** kopieren und **Update RDS** starten.
