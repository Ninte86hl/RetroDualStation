# RetroDualStation v12

## 🇬🇧 What's new

- **Artwork Manager on the device** (*Ports → Artwork Manager*) – boxart, cartridge icon and hero image
  for your games, with a live preview on the top screen. Single and batch search, game search across all
  systems, filter, **icon editor** with iiSU borders, your own images, backups of `gamelist.xml`.
- **Multi-disc games** can be merged into one `.m3u` entry (Artwork Manager settings).
- **Game search in ES:** press **Y** in the system view to search all systems; **A** jumps to the game.
- **Quick tour** – runs once after installing; start it again with **Select** in the Control Center.
  Also online: [docs/TOUR.md](../TOUR.md).
- Game switcher: **press Home twice** as an alternative to holding it.
- Hint lines everywhere show the button in **bold**.

### Fixes
- Bluetooth pairing window stays on one screen.
- ES menu shows Wi-Fi/Bluetooth correctly after switching them in the Control Center.
- **B** in the system list no longer opens the "Go to manufacturer" bar.
- PS1 games start: the installer selects **pcsx_rearmed** if the chosen core is missing.

### Install / update
Unpack `rocknix-dualstation-v12.zip` into `/storage/roms/ports` and run
*Ports → Install ROCKNIX DualStation*. Your games, media, game lists and saves are not touched.

## 🇩🇪 Neu

- **Artwork Manager am Gerät** (*Ports → Artwork Manager*) – Boxart, Cartridge-Icon und Hero-Bild für
  deine Spiele, mit Live-Vorschau oben. Einzel- und Mehrfachsuche, Spielesuche über alle Systeme, Filter,
  **Icon-Editor** mit iiSU-Rahmen, eigene Bilder, Sicherung der `gamelist.xml`.
- **Mehrteilige Spiele** lassen sich zu einem `.m3u`-Eintrag zusammenfassen (Einstellungen im Artwork Manager).
- **Spielesuche in ES:** **Y** in der Systemansicht durchsucht alle Systeme; **A** springt zum Spiel.
- **Kurze Tour** – läuft einmal nach der Installation; erneut mit **Select** im Kontrollcenter.
  Auch online: [docs/TOUR.de.md](../TOUR.de.md).
- Gameswitcher: **Home zweimal drücken** als Alternative zum Halten.
- Hinweiszeilen zeigen die Taste überall **fett**.

### Behoben
- Das Bluetooth-Koppeln-Fenster bleibt auf einem Bildschirm.
- Das ES-Menü zeigt WLAN/Bluetooth nach dem Umschalten im Kontrollcenter richtig an.
- **B** in der Systemliste öffnet nicht mehr die Leiste „Go to manufacturer“.
- PS1-Spiele starten: Der Installer wählt **pcsx_rearmed**, wenn der eingestellte Core fehlt.

### Installieren / Aktualisieren
`rocknix-dualstation-v12.zip` nach `/storage/roms/ports` entpacken und
*Ports → Install ROCKNIX DualStation* starten. Spiele, Medien, Spielelisten und Spielstände bleiben unberührt.
