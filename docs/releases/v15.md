# RetroDualStation v15

## 🇬🇧 What's new

### ScreenScraper in dual mode
- **Scraping works in dual mode** – RDS now has its own ScreenScraper developer access.
- Scraper progress appears **larger, centred at the bottom of the top screen** – easy to read on the RG DS, too.

### Control Center
- **Notifications on top** of the game:
  - battery low at 20 / 10 / 5 % (vibrates from 10 %), charger connected, battery full
  - Fast Forward / Slow Motion / Normal Speed, saved / loaded, screenshot
  - controller connected / disconnected, Wi-Fi on / off, headphones / speaker
  - RetroArch save slot, achievements when a game starts
- **RetroAchievements for DSperate**: page 3 and the unlock notification now work for DS games in DSperate, too.
- **DraStic: Anbernic + R1 (fast forward) and Anbernic + X (menu)** – the same shortcuts as everywhere else.
  On the RG DS Plus this also fixes fast forward starting when pushing the stick left.
- In a game, the Control Center opens on the **Game** page; in ES on the quick settings.
- **Brightness (top/bottom) and volume are kept** after a reboot.
- Power icon removed from the header – the power menu is on the power button.
- **Left stick** navigates the Control Center, Game switcher and power menu like the D-pad;
  **holding** a direction keeps scrolling.

### Game switcher
- **Swipe** left/right to switch games; tapping works anywhere on a tile.
- Switching to DSperate is about **1.3 s faster**.

### Artwork Manager
- Images in **pages of 12** – **L2 / R2** turns the page, the page number is shown on the top screen.
- **Choose the right game** when a name is ambiguous (e.g. *Resident Evil*); **Y** shows the result list first.
- **Batch with a waiting list**: a game joins the list automatically once every style is chosen
  (**Select** adds it with the current selection, or skips it). **Start** opens the list – **X** removes,
  **Y** moves up, **A** saves now. Everything is saved together when the batch ends, at 10 games or with Home.
- Ending a batch: **A** save and finish, **X** continue, **B** cancel (discard the list).
- **Nothing gets lost**: games not yet saved (empty battery, crash) are listed on the top screen at start
  and offered again when you open the system.
- Large view removed (the RG DS Plus has no R3).

### Fixes and details
- **ES on the RG DS Plus: the left stick moves the system carousel** again – the phantom right stick is removed
  from the ES button mapping (backup: `es_input.cfg.before-rds`).
- ES: *Fast shutdown system* is hidden in dual mode (it skips saving metadata).
- ES: *View this game's achievements* in the game options is hidden in dual mode (it only showed an error) –
  achievements are on page 3 of the Control Center while playing.
- Messages adapt to the text length in every language and never run off the screen.
- Performance profile in the Control Center applies to the running session (set it permanently in ES).

### Install / update
Unpack `retrodualstation-v15.zip` into `/storage/roms/ports` and run *Ports → Install RDS*.

## 🇩🇪 Neu

### ScreenScraper im Dual-Modus
- **Scrapen funktioniert im Dual-Modus** – RDS hat jetzt einen eigenen ScreenScraper-Entwicklerzugang.
- Der Scraper-Fortschritt erscheint **größer, unten mittig auf dem oberen Bildschirm** – auch auf dem RG DS gut lesbar.

### Kontrollcenter
- **Meldungen oben** über dem Spiel:
  - Akku schwach bei 20 / 10 / 5 % (ab 10 % mit Vibration), Ladegerät angeschlossen, Akku voll
  - Fast Forward / Slow Motion / Normal Speed, Gespeichert / Geladen, Screenshot
  - Controller verbunden / getrennt, WLAN an / aus, Kopfhörer / Lautsprecher
  - RetroArch-Speicherplatz, Erfolge beim Spielstart
- **RetroAchievements für DSperate**: Seite 3 und die Meldung bei neuen Erfolgen gibt es jetzt auch für DS-Spiele in DSperate.
- **DraStic: Anbernic + R1 (Vorspulen) und Anbernic + X (Menü)** – dieselben Kürzel wie überall.
  Auf dem RG DS Plus ist damit auch das Vorspulen beim Linksdrücken des Sticks behoben.
- Im Spiel öffnet das Kontrollcenter die Seite **Spiel**, in ES die Schnelleinstellungen.
- **Helligkeit (oben/unten) und Lautstärke bleiben** nach einem Neustart erhalten.
- Power-Symbol aus der Kopfzeile entfernt – das Power-Menü liegt auf der Ein/Aus-Taste.
- Der **linke Stick** steuert Kontrollcenter, Gameswitcher und Power-Menü wie das Steuerkreuz;
  **Halten** schaltet automatisch weiter.

### Gameswitcher
- **Wischen** nach links/rechts wechselt das Spiel; Antippen funktioniert überall auf der Kachel.
- Der Wechsel zu DSperate ist etwa **1,3 s schneller**.

### Artwork Manager
- Bilder in **Seiten zu je 12** – **L2 / R2** blättert, die Seite steht auf dem oberen Bildschirm.
- **Das richtige Spiel wählen**, wenn ein Name nicht eindeutig ist (z. B. *Resident Evil*); **Y** zeigt zuerst die Trefferliste.
- **Batch mit Warteliste**: Ein Spiel kommt automatisch in die Liste, sobald alle Stile gewählt sind
  (**Select** reiht es mit der bisherigen Auswahl ein oder überspringt es). **Start** öffnet die Liste – **X** entfernt,
  **Y** schiebt nach oben, **A** speichert sofort. Gespeichert wird gesammelt beim Beenden, bei 10 Spielen oder mit Home.
- Batch beenden: **A** speichern und beenden, **X** weiter, **B** abbrechen (Liste verwerfen).
- **Nichts geht verloren**: Noch nicht gespeicherte Spiele (Akku leer, Absturz) stehen beim Start oben in einer Liste
  und werden beim Öffnen des Systems erneut angeboten.
- Großansicht entfernt (das RG DS Plus hat kein R3).

### Behoben und Details
- **ES auf dem RG DS Plus: Der linke Stick bewegt das System-Karussell** wieder – der Phantom-Stick wird aus der
  ES-Tastenbelegung entfernt (Sicherung: `es_input.cfg.before-rds`).
- ES: *Fast Shutdown System* ist im Dual-Modus ausgeblendet (es überspringt das Speichern der Metadaten).
- ES: *Erfolge dieses Spiels* in den Spieloptionen ist im Dual-Modus ausgeblendet (zeigte nur einen Fehler) –
  die Erfolge stehen im Spiel auf Seite 3 des Kontrollcenters.
- Meldungen passen sich in jeder Sprache der Textlänge an und laufen nie über den Rand.
- Das Leistungsprofil im Kontrollcenter gilt für die laufende Sitzung (dauerhaft in ES einstellen).

### Installieren / Aktualisieren
`retrodualstation-v15.zip` nach `/storage/roms/ports` entpacken und *Ports → Install RDS* starten.
