## 🇬🇧 v6 – first release

First public release of the dual-screen EmulationStation mod for the **Anbernic RG DS Plus** on **ROCKNIX**.

### Highlights
- ES spans both screens (2048 × 768): ROCKNIX logo on top, system view on the bottom
- Menus, popups, loading screens and the BIOS check stay on the top screen
- Bottom screen no longer turns off after returning from a game
- Switch between this build and stock ES via Ports (incl. theme switch)
- Includes the dii-ess-aye-rgds-plus theme (MIT, based on dii-ess-aye by beebono)

### Downloads
- `dii-ess-aye-rocknix-dual-mod-v6.tar.gz` – complete package: ES binary, device scripts, essway drop-in, RG DS Plus theme, docs and licenses
- `emulationstation-rgds-v6` – ES binary only (aarch64)

### Requirements · Limitations
- Anbernic RG DS Plus with ROCKNIX (tested with 20261001, ES commit cada856)
- No ScreenScraper / RetroAchievements in this build – switch to stock ES via Ports to scrape

## 🇩🇪 v6 – erste Version

Erste öffentliche Version des Dual-Screen-EmulationStation-Mods für das **Anbernic RG DS Plus** mit **ROCKNIX**.

### Highlights
- ES nutzt beide Bildschirme (2048 × 768): ROCKNIX-Logo oben, Systemansicht unten
- Menüs, Meldungen, Ladebildschirme und die BIOS-Prüfung bleiben auf dem oberen Bildschirm
- Der untere Bildschirm geht nach einem Spiel nicht mehr aus
- Umschalten zwischen diesem Build und dem Original-ES über Ports (inklusive Theme-Wechsel)
- Enthält das Theme dii-ess-aye-rgds-plus (MIT, basierend auf dii-ess-aye von beebono)

### Downloads
- `dii-ess-aye-rocknix-dual-mod-v6.tar.gz` – komplettes Paket: ES-Binary, Geräteskripte, essway-Drop-in, RG-DS-Plus-Theme, Doku und Lizenzen
- `emulationstation-rgds-v6` – nur das ES-Binary (aarch64)

### Voraussetzungen · Einschränkungen
- Anbernic RG DS Plus mit ROCKNIX (getestet mit 20261001, ES-Commit cada856)
- Kein ScreenScraper / keine RetroAchievements in diesem Build – zum Scrapen per Ports auf das Original-ES wechseln
