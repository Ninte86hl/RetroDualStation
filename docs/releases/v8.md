## 🇬🇧 ROCKNIX DualStation v8 – easy installation

No more SSH: v8 comes as a ZIP with an installer in the Ports menu.

### Install
1. Download **`rocknix-dualstation-v8.zip`** below.
2. Unpack it into the `ports` folder of your ROMs (`/storage/roms/ports`).
3. In EmulationStation, start **Ports → Install ROCKNIX DualStation**.

The installer checks that the device is an RG DS Plus and that the included EmulationStation works with your ROCKNIX version. If not, it shows a message and changes nothing.
Already using an earlier version? Just unpack the ZIP and run the installer – it updates your installation.

### Uninstall
**Ports → Uninstall ROCKNIX DualStation** switches back to stock ROCKNIX ES and removes all files of ROCKNIX DualStation. Games, media, game lists and saves are not touched.

### Changes since v7
- New installer and uninstaller as Ports entries
- README: tip for DraStic – if touch does not work, set *Follow 3D Renderer* to *Auto*
- EmulationStation unchanged (same build as v7)

Supported: **Anbernic RG DS Plus**. RG DS support is in the works.

## 🇩🇪 ROCKNIX DualStation v8 – einfache Installation

Kein SSH mehr: v8 kommt als ZIP mit Installer im Ports-Menü.

### Installieren
1. **`rocknix-dualstation-v8.zip`** unten herunterladen.
2. In den Ordner `ports` deiner ROMs entpacken (`/storage/roms/ports`).
3. In EmulationStation **Ports → Install ROCKNIX DualStation** starten.

Der Installer prüft, ob das Gerät ein RG DS Plus ist und ob das mitgelieferte EmulationStation zu deiner ROCKNIX-Version passt. Wenn nicht, zeigt er eine Meldung und ändert nichts.
Schon eine ältere Version installiert? Einfach die ZIP entpacken und den Installer starten – er aktualisiert die Installation.

### Deinstallieren
**Ports → Uninstall ROCKNIX DualStation** schaltet zurück auf das Original-ES von ROCKNIX und entfernt alle Dateien von ROCKNIX DualStation. Spiele, Medien, Spielelisten und Spielstände bleiben unberührt.

### Änderungen seit v7
- Neuer Installer und Uninstaller als Ports-Einträge
- README: Tipp für DraStic – reagiert Touch nicht, *Follow 3D Renderer* auf *Auto* stellen
- EmulationStation unverändert (gleicher Build wie v7)

Unterstützt: **Anbernic RG DS Plus**. Unterstützung für das RG DS ist in Arbeit.
