# RetroDualStation v15.3.1

## 🇬🇧 What's new
- **Saving by hand goes to Slot 1** in every emulator: **Anbernic + R2 / L2** saves to and loads from **Slot 1**
  (RetroArch, DraStic, DSperate) – before, it went to the automatic save point. Only Home, quitting and the game
  switcher use **Automatic**. In RetroArch, **Anbernic + ◀ / ▶** stays within slots 1–9.
- **DSperate:** a state saved by hand on slot 0 now shows up as **Automatic** in the load menu, and loading
  *Automatic* no longer overwrites a newer state.

- **Everything RDS creates starts with `rds-`** – e.g. `/storage/rds-install.log`, `roms/backup/rds-original-backup.zip` –
  so it is easy to tell apart. Updating renames existing files. No more backup copies next to the emulator settings.

Updating from v15.3: copy the package into **ports** and start **Update RDS**.

## 🇩🇪 Neu
- **Manuell speichern geht auf Slot 1** – in jedem Emulator: **Anbernic + R2 / L2** speichert bzw. lädt **Slot 1**
  (RetroArch, DraStic, DSperate) – bisher landete es auf dem automatischen Speicherpunkt. Nur Home, Beenden und der
  Gameswitcher nutzen **Automatisch**. In RetroArch bleibt **Anbernic + ◀ / ▶** bei Slot 1–9.
- **DSperate:** Ein von Hand auf Platz 0 gespeicherter Stand erscheint im Laden-Menü als **Automatisch**, und Laden aus
  *Automatisch* überschreibt keinen neueren Stand mehr.

- **Alles, was RDS anlegt, beginnt mit `rds-`** – z. B. `/storage/rds-install.log`, `roms/backup/rds-original-backup.zip` –
  so lässt es sich leicht erkennen. Ein Update benennt vorhandene Dateien um. Keine Sicherungskopien mehr neben den
  Emulator-Einstellungen.

Update von v15.3: Paket in **ports** kopieren und **Update RDS** starten.
