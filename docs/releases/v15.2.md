# RetroDualStation v15.2 (in Arbeit)

## 🇬🇧 What's new

### Fast switch (opt-in, test phase)
- Switching between games in the game switcher can keep the previous game **paused in memory** instead of closing it.
  Going back to it takes about **half a second** instead of 4–6 s. Works with **DSperate, DraStic and RetroArch**
  (RetroArch once the game has been opened in the game switcher while playing).
- The parked game is moved to an invisible workspace and frozen; inputs pressed in the other game are discarded
  before it wakes up, so nothing is replayed.
- Quitting a game with Home (or from the Control Center) always leads back to ES – the parked game is closed, too.
- Compressed memory (zram) is used only while fast switch is enabled.

### Touch after DraStic fixed
- After a DraStic game, DSperate (and other games) lost touch on the bottom screen. Cause: a ROCKNIX window rule maps
  the touchscreen to the other screen as soon as a DraStic window appears and never resets it. RDS now restores the
  mapping when switching away from DraStic (and re-applies it for DraStic).
- Switching away from DraStic in the game switcher is fast again (≈4 s instead of ≈8 s): the detour via ES is no longer needed.

### Control Center
- **Swipe gesture**: swipe down from the top edge of the bottom screen opens the Control Center, swipe up from the
  bottom edge closes it. Works in ES and RetroArch games (not in DSperate / DraStic – their bottom screen belongs to the game).

## 🇩🇪 Neu

### Schnellwechsel (zum Einschalten, Testphase)
- Beim Wechsel im Gameswitcher kann das vorherige Spiel **pausiert im Speicher** bleiben, statt beendet zu werden.
  Zurück dauert es etwa **eine halbe Sekunde** statt 4–6 s. Funktioniert mit **DSperate, DraStic und RetroArch**
  (RetroArch, sobald das Spiel einmal beim Spielen im Gameswitcher geöffnet wurde).
- Das geparkte Spiel liegt auf einem unsichtbaren Arbeitsbereich und ist eingefroren; Tasten aus dem anderen Spiel
  werden vor dem Aufwecken verworfen, damit nichts nachgespielt wird.
- Beenden per Home (oder über das Kontrollcenter) führt immer zurück zu ES – das geparkte Spiel wird mit beendet.
- Komprimierter Speicher (zram) ist nur aktiv, solange der Schnellwechsel eingeschaltet ist.

### Touch nach DraStic behoben
- Nach einem DraStic-Spiel hatte DSperate (und andere Spiele) unten keinen Touch mehr. Ursache: Eine ROCKNIX-Fensterregel
  ordnet den Touchscreen beim Erscheinen eines DraStic-Fensters dem anderen Bildschirm zu und setzt das nie zurück.
  RDS stellt die Zuordnung beim Wechsel weg von DraStic wieder her (und für DraStic wieder ein).
- Wechsel weg von DraStic im Gameswitcher wieder schnell (≈4 s statt ≈8 s): Der Umweg über ES ist nicht mehr nötig.

### Kontrollcenter
- **Wischgeste**: Vom oberen Rand des unteren Bildschirms nach unten wischen öffnet das Kontrollcenter, vom unteren
  Rand nach oben schließt es. In ES und RetroArch-Spielen (nicht in DSperate/DraStic – dort gehört der untere Bildschirm dem Spiel).
