# RetroDualStation v15.3.4

## 🇬🇧 What's new
- **Microphone: the Control Center listens itself** – blowing into the microphone of the RG DS / RG DS Plus works in
  DraStic without ROCKNIX's microphone detection (which is switched off again; v15.3.3 had set it to *medium*).
  Blowing triggers it, normal talking does not – shouting does, just like on a real DS. Works the same with **L3**.
  **RG DS:** its built-in microphone is not yet picked up by ROCKNIX (only noise arrives) – use **L3** there.
- **advanced_drastic (trngaje) works with RDS** – if you installed it yourself: quitting via Home / Control Center,
  automatic save point, auto-load, swap tile, shortcuts. (Not bundled; on the RG DS Plus it needs its own layout file.)
- **Fix:** ES could react to every button twice after an emulator crashed at start (leftover key helper) – the Control
  Center now ends it automatically.

Updating from v15.3.3: copy the package into **ports** and start **Update RDS**.

## 🇩🇪 Neu
- **Mikrofon: Das Kontrollcenter hört selbst zu** – ins Mikrofon des RG DS / RG DS Plus pusten funktioniert in DraStic
  ohne die ROCKNIX-Mikrofonerkennung (die wieder aus ist; v15.3.3 hatte sie auf *medium* gestellt). Pusten löst aus,
  normales Reden nicht – lautes Rufen schon, wie am echten DS. Mit **L3** wie bisher.
  **RG DS:** Sein eingebautes Mikrofon kommt bei ROCKNIX noch nicht an (nur Rauschen) – dort **L3** nutzen.
- **advanced_drastic (trngaje) läuft mit RDS** – falls selbst installiert: Beenden über Home/Kontrollcenter, automatischer
  Speicherpunkt, Auto-Laden, Kachel „Tauschen“, Kürzel. (Nicht mitgeliefert; auf dem RG DS Plus braucht es eine eigene
  Layout-Datei.)
- **Behoben:** Stürzte ein Emulator beim Start ab, konnte ES jede Taste doppelt bekommen (übrig gebliebener
  Tastenhelfer) – das Kontrollcenter beendet ihn jetzt selbst.

Update von v15.3.3: Paket in **ports** kopieren und **Update RDS** starten.
