# RetroDualStation – Kurze Tour

*[English version](Tour)*

RetroDualStation macht ROCKNIX auf dem Anbernic RG DS Plus zu **einem System mit zwei Bildschirmen**.
Diese Tour zeigt die Erweiterungen zu EmulationStation: die zwei Sondertasten, das Kontrollcenter,
den Gameswitcher, das Power-Menü und den Artwork Manager.

Dieselbe Tour läuft nach der Installation einmal auf dem Gerät. Du kannst sie jederzeit im
Kontrollcenter mit **Select** erneut starten.

---

## 1. Die zwei Sondertasten

<p align="center"><img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/geraet-tasten.png" alt="Anbernic-Taste und Home-Taste am RG DS Plus" width="560"></p>

| Taste | Drücken | Funktion |
|---|---|---|
| **Anbernic** | kurz | **Kontrollcenter** öffnen / schließen |
| **Home** | kurz | Im Spiel: **speichern** und zurück zu EmulationStation |
| **Home** | lang (1,5 s) | **Gameswitcher** öffnen |
| **Home** | 2× | Im Spiel: direkt zum **vorherigen Spiel** (in ES: Gameswitcher) |
| **Power** | kurz | **Power-Menü** öffnen |
| **Power** | lang (0,8 s) | Sofort **Ruhemodus** |

## 2. Kontrollcenter

<p align="center"><img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-kontrollcenter.png" alt="Kontrollcenter" width="480"></p>

Öffnen mit der **Anbernic**-Taste – in EmulationStation und in jedem Spiel (das Spiel pausiert).

- **Läuft gerade:** das laufende Spiel mit *Spiel beenden*.
- **Helligkeit** oben und unten sowie **Lautstärke** – mit dem Steuerkreuz oder per Touch.
- **Leistung:** Sparen · Ausgewogen · Leistung.
- **Kacheln:** WLAN und Bluetooth (**X / Y** – Details und Koppeln), *Unterer Screen aus*
  (mit der Anbernic-Taste wieder einschalten) und *Ruhemodus*.
- Oben rechts: Power-Menü, helles/dunkles Design und Akzentfarbe.

**L1 / R1** – Seite wechseln · **B** – Schließen · **Select** – diese Tour erneut starten

### Seite „Spiel“

| | |
|---|---|
| <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-spiel.png" alt="Seite Spiel"> | <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-slots.png" alt="Speicherplätze"> |

Im Spiel mit **R1** zur Seite „Spiel“ (RetroArch, DSperate und DraStic):
- **Speichern / Laden** öffnen die Speicherplätze 0–8 mit Vorschaubild und Uhrzeit. Beim Laden ist der neueste vorausgewählt.
  Der **Mülleimer** (oder **X**, **X**) löscht einen Spielstand.
- Symbole: **Emulator-Menü · Neu starten · Vorspulen · Zeitlupe · Screenshot · Tasten · Beenden**.
- **Tasten** zeigt die Original-Tasten des Systems (z. B. NES: Steuerkreuz, A, B, Select, Start) und die Kürzel des Emulators.
- Nach einer Aktion schließt sich das Kontrollcenter und du bist wieder im Spiel.

### Kürzel – in jedem Emulator gleich

<p align="center"><img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-tasten.png" alt="Tastenbelegung" width="480"></p>

**Anbernic-Taste halten** und eine zweite Taste drücken. Alles geht auch per Tipp im Kontrollcenter.

| Anbernic + | Aktion |
|---|---|
| **R1** | Vorspulen an/aus |
| **R2 / L2** | Speichern / Laden |
| **X** | Emulator-Menü |
| **Y** | FPS anzeigen |
| **Start** | Spiel beenden |
| **◀ / ▶** | Speicherplatz − / + |

DraStic kennt keine Tastenkombinationen: Dort liegen Speichern und Laden auf R2 und L2, Menü und Vorspulen gibt es über das Kontrollcenter.

### RetroAchievements (Seite 3)

| | |
|---|---|
| <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-ra.png" alt="RetroAchievements"> | <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-toast.png" alt="Erfolg freigeschaltet"> |

Dein Konto, der Fortschritt im laufenden Spiel und alle Erfolge – **A** öffnet einen Erfolg mit Beschreibung,
Punkten und Seltenheit. Ein neuer Erfolg erscheint kurz **oben über dem Spiel**, ebenso die **Lautstärke** bei Vol+ / Vol−.
Anmelden in ES: *Spieleinstellungen → RetroAchievements-Einstellungen*. Unterstützt werden RetroArch-Spiele.

## 3. Gameswitcher

<p align="center"><img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-gameswitcher.png" alt="Gameswitcher" width="480"></p>

**Home** 1,5 Sekunden halten. Im Spiel bringt dich **Home zweimal** direkt zum vorherigen Spiel. Die zuletzt gespielten Spiele erscheinen als Karten mit ihrem letzten Bild.
Beim Wechseln wird das laufende Spiel automatisch gesichert und das nächste dort fortgesetzt,
wo du aufgehört hast.

**◀ ▶** – wählen · **A** – Weiterspielen · **Y** – Neu starten · **X** – Aus der Liste entfernen · **B** – Schließen

---

## 4. Power-Menü

<p align="center"><img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-powermenue.png" alt="Power-Menü" width="480"></p>

**Power** kurz drücken: *Ruhemodus*, *Neu starten*, *Ausschalten* und *ES neu starten*.
Power gedrückt halten schickt das Gerät sofort in den Ruhemodus.

**▲ ▼** – wählen · **A** – bestätigen · **X** – Details · **B** – abbrechen

## 5. Artwork Manager

| | |
|---|---|
| <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-artwork-liste.png" alt="Spieleliste mit Filter"> | <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-artwork-settings.png" alt="Einstellungen"> |
| <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-artwork-spiel.png" alt="Spielansicht mit Mix-Vorschau"> | <img src="https://raw.githubusercontent.com/Ninte86hl/RetroDualStation/main/docs/tour/tour-artwork-editor.png" alt="Icon-Editor"> |

Start über **Ports → Artwork Manager**. Er ergänzt **Boxart**, **Cartridge** (1:1-Icon) und
**Image** (Hero) – der obere Bildschirm zeigt, wie die drei zusammen wirken.

**Voraussetzung:** Jedes System braucht eine `gamelist.xml`. Sie entsteht einmalig mit dem Scraper
im Single-Screen-Modus (originale ROCKNIX-Oberfläche); RetroDualStation nutzt dieselbe Liste.

| Wo | Taste | Funktion |
|---|---|---|
| Systemliste | **Start** | Einzelsuche: ein Spiel bearbeiten |
| | **Select** | Mehrfachsuche: alle Spiele mit fehlenden Artworks nacheinander |
| | **Y** | Spiel über alle Systeme suchen |
| | **X** | Einstellungen (API-Key, Sicherungen, mehrteilige Spiele per M3U zusammenfassen, Zwischenspeicher, Kurzanleitung) |
| Spieleliste | **X** | Direkt in den Icon-Editor für dieses Spiel |
| | **Y** | Filter: alle · fehlende · keine Artworks |
| Spielansicht | **◀ ▶** | Bild wählen |
| | **L / R** | Artwork-Stil |
| | **A** | Bild übernehmen |
| | **Start** | Speichern |
| | **Y** | Anderes Spiel suchen |
| | **L3** | Artwork-Suche aktualisieren |
| | **R3** | Mix-Ansicht / Großansicht oben |
| | **X** | Icon-Editor: aus dem gewählten Icon ein 1:1-Bild mit iiSU-Rahmen machen (◀ ▶ ▲ ▼ verschieben · L / R Zoom · Y Rahmen). Bei Icons, die den iiSU-Rahmen schon haben, nicht nötig und ausgegraut |

Vor dem ersten Speichern pro System wird eine Sicherung angelegt (in den Einstellungen abschaltbar).
**Eigene Bilder:** PNG-, JPG- oder WebP-Dateien in `ports/artworkmanager/eigene/` (oder `eigene/<System>/`) legen und wie das Spiel benennen – sie erscheinen vorn in jedem Tab als *Eigenes Bild*. Alles in `eigene/alle/` erscheint bei jedem Spiel.

Den SteamGridDB-API-Key kannst du auch am PC eintragen:
`/storage/roms/ports/artworkmanager/settings.cfg`.
